### 1. ARs with Data Inconsistencies

#### **AR 1: HVAC Tune-Up**
*   **Inconsistency:** The summary text lists annual savings as **$8,06**, whereas the numerical data confirms **$8,066**.
*   **Impact:** The summary text contains a significant typo (truncated digit), underrepresenting savings by a factor of 10.

#### **AR 2: Compressed Air System**
*   **Inconsistency:** The summary text specifies an implementation cost of **$10**, but the `implementation_cost` field is missing from the Numerical Data Matches list.
*   **Impact:** Disconnect between narrative and structured data.

#### **AR 4: Eliminate Leaks**
*   **Inconsistency:** The summary text specifies an implementation cost of **$45**, but the `implementation_cost` field is missing from the Numerical Data Matches list.
*   **Impact:** Disconnect between narrative and structured data.

#### **AR 5: High Efficiency Lighting**
*   **Inconsistency:** The summary text contains a **verbatim duplicate sentence**: *"Upgrading to higher efficiency lamps and/or ballasts will significantly reduce electrical consumption while maintaining required lighting levels"* appears at both the beginning and the end of the paragraph.
*   **Impact:** Professionalism/formatting issue; redundant reading.

### 2. Common Patterns in Discrepancies

1.  **Missing Implementation Cost Fields:** In both AR 2 and AR 4, the narrative provides an implementation cost, but the structured numerical data fails to capture/match that specific field.
2.  **Narrative Truncation/Typos:** Financial figures in the summary text (AR 1) are prone to manual entry errors that do not align with the backend calculations.
3.  **Redundancy/Editing Errors:** AR 5 suggests a lack of final proofreading, resulting in "copy-paste" errors where sentences are repeated.

### 4. Recommendations for Corrections

#### **Immediate Technical Corrections:**
*   **AR 1:** Update summary text to: "...estimated to be **$8,066** with no implementation cost."
*   **AR 2:** Add `implementation_cost: 10` to the numerical data matches.
*   **AR 4:** Add `implementation_cost: 45` to the numerical data matches.
*   **AR 5:** Delete the second occurrence of the sentence: *"Upgrading to higher efficiency lamps and/or ballasts will significantly reduce electrical consumption while maintaining required lighting levels."*

#### **Process Improvements:**
1.  **Automated Text Sync:** Implement a system where the dollar amounts in the "Summary Text" are dynamically pulled from the numerical data fields to prevent manual typing errors (like the one in AR 1).
2.  **Field Validation:** Ensure the validation script flags an error if a value (like Implementation Cost) is mentioned in the text but is null or missing in the structured data.
3.  **Deduplication Filter:** Run a simple string-check algorithm to identify and flag repeating sentences within a single summary paragraph.
