### 1. Analysis of ARs with Data Inconsistencies

**AR 1: HVAC Tune-Up**
*   **Discrepancy:** The summary text lists annual savings as **$8,06**, while the numerical data record shows **$8,066**.
*   **Missing Field:** The implementation cost is listed as $0 in the data matches but is noted as "no implementation cost" in the text (this is consistent, but the typo in the savings figure is a primary concern).

**AR 2: Compressed Air System Pressure**
*   **Discrepancy:** The summary text states an implementation cost of **$10**. However, the numerical data shows a payback period of **0.04 years**. 
    *   *Calculation:* $2,792 (savings) × 0.04 (payback) = **$111.68**. 
    *   A $10 cost with $2,792 savings should result in a payback of **0.003 years**.
*   **Data Omission:** The `implementation_cost` field is missing from the "Numerical Data Matches" list.

**AR 4: Compressed Air Leaks**
*   **Data Omission:** While the text and numerical data for savings and payback align ($45 / $905 ≈ 0.05), the field `implementation_cost` is **missing** from the Numerical Data Matches list.

**AR 5: High Efficiency Lamps/Ballasts**
*   **Text Redundancy:** The summary text repeats the entire final sentence: *"Upgrading to higher efficiency lamps and/or ballasts will significantly reduce electrical consumption while maintaining required lighting levels"* appears twice.
*   **Data Consistency:** The numbers ($9,783 savings, $6,965 cost, 0.71 payback) are mathematically consistent.

### 2. Common Patterns in Discrepancies

1.  **Decimal/Typo Errors in Summary Text:** There is a recurring issue where the summary text truncates or mistypes numerical values (e.g., $8,06 instead of $8,066).
2.  **Implementation Cost Mapping:** The `implementation_cost` field is frequently missing from the structured data matches (AR 2 and AR 4), even when it is mentioned in the summary text.
3.  **Calculation Misalignment:** There is a disconnect between the "simple payback" calculation and the reported implementation cost in the text (notably in AR 2).
4.  **Formatting/Editing Oversight:** Textual summaries contain redundant sentences, suggesting a lack of final proofreading before validation.

### 4. Recommendations for Corrections

#### Immediate Data Fixes:
*   **AR 1:** Correct the summary text to display **$8,066** instead of $8,06.
*   **AR 2:** Verify the actual implementation cost. If the payback is 0.04, update the text to **$112**. If the cost is truly $10, update the payback period to **0.00** (or 0.004).
*   **AR 5:** Remove the duplicate sentence at the end of the summary.

#### Process Improvements:
*   **Automated Validation:** Implement a script that flags any AR where `implementation_cost / total_cost_savings` does not equal the `payback_period` (within a rounding tolerance).
*   **Field Mapping:** Ensure the `implementation_cost` field is properly indexed in the database so it appears in the "Numerical Data Matches" for all ARs.
*   **Text Formatting:** Apply a "unique sentence" filter to the summary generation tool to prevent the verbatim repetition of descriptions seen in AR 5.
*   **Currency Masking:** Ensure the summary generation tool uses standard currency formatting (e.g., $8,066.00) to prevent truncation errors like the one in AR 1.
